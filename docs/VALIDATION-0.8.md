## 首轮未完成项与限制（后续状态见补充报告）

- OPPO 真机完整上传重连测试：首块上传成功、重新认证成功，随后请求超时；补充日志显示 CPU 唤醒锁约 10 秒后被设备侧回收/代理，测试定时器也延迟。启用既有后台服务后仍复现。此结果保留为失败，不能把整个重连问题全部归因为系统限制，也不能声称真机端到端通过。
- `android-media-live-*.txt` 保留各次失败。为诊断向本任务测试进程发送 SIGQUIT 获取线程栈，没有停止其他应用、改省电白名单、点亮屏幕、解锁、锁屏或重启。20 项短测试通过不覆盖长时间后台运行。
- 用户不在设备旁；真实文件选择、拍照、录音识别、图片缩放手势、分享目标、键盘与新聊天布局的目视验收待解锁后进行。
- 原公网部署实例仍为 0.7，未将尚未完成真机长链路验收的版本覆盖到日常实例。已安装 0.8 手机仍可使用旧电脑文字功能；附件需要 0.8 电脑能力。
- Windows 安装包未作可信代码签名；Android 使用原 debug 签名以保留绑定。正式 release 仍需受控签名。
- 本地 `update.json` 是待发布清单，引用的 v0.8.0 Release 地址尚未发布，不是可用在线更新承诺。
- 没有完整 CommonMark、数学公式、代码着色、实时语音对话、文档内容解析保证；系统语音服务可能联网。电脑附件文件正文并非磁盘加密，元数据受系统保护；手机私有缓存加密。
