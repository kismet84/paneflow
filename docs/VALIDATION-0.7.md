# PaneFlow 0.7 验证报告

日期：2026-11-02。Windows / Android 0.7.0，Android versionCode 9；协议版本 1，按能力协商扩展。

## 实现范围

- Windows 配置向导检查 Codex、Node、cloudflared、工作目录、端口、已有固定域名隧道配置及本地/公网健康状态；验证实例身份后才能启用登录自启。不会创建或覆盖云端隧道。
- 托管中继与隧道具有独立子进程看护、断线恢复和准确退出；保留现有部署实例的原自启方式，避免启动两套服务。
- Android 增加原生扫码填入配对链接，仍需电脑核对六位数字；保留粘贴链接、原生聊天与后台连接。
- 双端更新入口检查版本、协议、下载来源、大小和 SHA-256；Android 另外核对包名、版本、系统要求和签名。任务或未核对回执阻止升级。
- Windows 升级前备份程序与配置，校验启动身份及 Codex 就绪；失败先准确退出本次新程序，再恢复。Android 覆盖安装使用原签名，密钥保留在 Keystore。
- 补充 CI 检查、手动触发的安装包构建、校验清单和更新清单生成。签名材料不进入仓库。

## 验收边界

- 设备层级为一台 Windows 的多个隔离实例/客户端与一台 OPPO K10，不代表两台物理电脑、两台手机验收通过。
- Windows 安装验证使用本机新目录，不是干净 Windows 虚拟机；没有重启 Windows 验证登录事件。已核对既有登录任务及实际启动/恢复。
- 扫码验证覆盖 ZXing 编解码和配对输入路径，未把仪器测试称为真实摄像头对准二维码验收。
- 最后补做公网新会话 UI 回归时系统报告 Keyguard showing=true，用户不在设备旁；未绕过锁屏，补测待解锁后进行。此前 21 项仪器测试、真实队列/聊天及公网认证结果仍有效；失败辅助入口日志单独保留，未计入通过项。
- 本轮隔离测试实例及 USB 48433 转发已关闭。手机中测试电脑 `电脑 18386e` 的绑定暂留，后台默认关闭；它显示离线属于预期。解锁后可在电脑管理移除该测试绑定，再做要求所有已配置电脑在线的升级验收，不影响“工作电脑”原绑定。
- 更新清单与安装包已在本地生成，未发布 GitHub Release；固定在线更新地址尚无本次版本。没有声称远端 CI 或商店更新已经执行。
- Windows 未签名；APK 使用原本机 debug 签名以保留既有绑定。正式发布流水线要求受控 release 签名，缺少签名材料会拒绝 release 构建。
- 手动安装到旧自定义目录时需选择原目录；应用内更新通过 `/D` 指定原目录。新安装器不执行旧卸载器。
- 0.5、0.6 安装包保留作阶段证据，日常安装使用最终 0.7 安装器，避免旧安装流程对其他实例的影响。
- 全程未执行锁屏、未重启手机或 Windows，未操作其他 Codex 窗口的任务。系统后来进入锁屏，已停止依赖解锁的 UI 补测。没有提交、推送或远端发布。

程序、校验值、更新清单和阶段报告位于 `release/stage-0.7.0/`。本地验证输出与恢复材料留在忽略目录，不进入公开仓库。
