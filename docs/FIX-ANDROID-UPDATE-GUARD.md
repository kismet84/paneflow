# Android 更新误拦截修复

2026-11-03。MatePad Pro 原安装版本 0.8.0 / 10；Windows 已升级 0.8.1，平板仍显示“更新暂缓：工作电脑：还有运行中或未知状态的会话”。

## 原因与修改

`NativeUpdateGuard.checkState` 把 snapshot.threads 中所有记录均为 idle/failed 作为升级条件。此列表来自全库历史及运行状态推断，包含其他官方 Codex 进程、状态未知的旧会话，不能代表需要停止的本机工作。

本次只删除该历史列表检查。仍要求每台已配对电脑在线、认证通过、快照新鲜、执行服务 ready，当前轮次无活动，完整队列没有待执行或结果不明项目，审批为空；本机持久存储正常，所有已保存请求回执明确完成或失败。安装仍执行加密数据备份及安装包大小、SHA256、包名、版本、签名校验。

仅适用于 Android 客户端升级。电脑任务不会因 Android 断连被停止；其他非当前会话可能仍在执行，本次检查通过不代表所有任务空闲。Windows 服务升级条件未改变。

- 指定独立验收会话接管 → 草稿保留 → 释放恢复只读 → 再接管 → 恢复原草稿 → 释放，真机测试通过。

- 全程未执行锁屏；未停止电脑上的其他任务。
