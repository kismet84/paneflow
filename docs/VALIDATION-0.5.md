# PaneFlow 0.5 验证报告

日期：2026-11-02。Android 0.5.0 / code 7；Windows 0.5.0；协议版本 1，新增能力协商。

## 交付范围

- 多电脑绑定、命名、选择、移除；旧单电脑身份与后台开关原地沿用。
- 按设备隔离会话投影和订阅；按电脑/会话保存草稿、阅读锚点和请求记录。
- 发送前持久记录稳定请求 ID；桌面系统加密回执、重启结果查询、不自动重放未知副作用；部分新建成功可定位实际新会话。
- 正文分页、大页分段、签名游标、重叠去重，原生 ListView 复用和滚动位置恢复。
- 分层诊断、脱敏导出、多电脑后台连接与通知定位。
- Windows 安装包及 Android 覆盖升级包。新安装数据在程序目录之外；已有便携数据不静默迁移，安装/卸载遇到该数据目录会停止保护。

## 修复与复核

独立只读复核发现并修复：跨会话审批广播/目标校验、部分新建成功的回执目标丢失、缺正文误判空历史、通知与 Bundle 跨电脑归属、重复通知消费、跨电脑重新配对、历史重叠顺序、旧便携数据的安装器保护。真机补测发现并修复 ListView padding 导致阅读位置漂移。

## 验证边界

- 本次只有一台物理 Windows 和一台 OPPO；“第二电脑”和“第二手机客户端”分别是同机隔离实例和浏览器，不能当作两台物理设备通过。
- 700 项长历史采用隔离测试数据验证实际原生列表；真实会话验证覆盖发送、继续、分页、重连。未为长历史测试批量生成真实模型轮次。
- 未锁屏、未重启整台 Windows。当前用户登录自启使用已有计划任务实际启动；干净环境安装、完整升级回退属于 0.7。
- Windows 安装包未配置代码签名证书；Android 沿用本机原型签名保证覆盖升级。签名材料未进入仓库。
- 同一 Codex 数据目录被另一 app-server 持有写入权时，打开会话会明确报 active writer；测试改用所属实例的新会话，没有绕过进程控制边界。
- 尚未进行 0.6 队列/聚合审批和 0.7 完整配置/更新验收。
