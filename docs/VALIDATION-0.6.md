## 证据与边界

- 本地证据位于 `outputs/stage-0.6/`，不提交含本地状态的输出目录。包括仪器日志、队列重启/执行/取消/停止快照、真实轮次记录、原生截图。
- 使用一台 Windows 的隔离实例和一台 OPPO K10；并发审批由两个隔离协议客户端验证，不代表两台真机同时审批已通过。
- 重启未知执行、审批占槽和磁盘错误使用可重复自动测试；真实设备验证暂停队列重启。没有将故障注入测试声称为断电恢复验收。
- 保留生产 0.5 实例运行；0.6 Windows 安装包单独提供，隔离实例运行新版。最终部署在 0.7 阶段完成。
- Windows 安装包未配置代码签名（NotSigned）；Android 使用已有本机 debug 签名，覆盖安装保留身份。正式分发需独立受控签名配置。
- 全程没有锁屏、重启手机或重启 Windows；没有操作其他 Codex 窗口的任务。

安装包与 SHA-256 清单位于 `release/stage-0.6.0/`。
