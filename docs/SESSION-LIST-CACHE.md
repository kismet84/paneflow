# 会话列表缓存

2026-11-02，基线 640fb5b，本地 Android 增量。

- 每台电脑独立保存会话列表、当前搜索条件和分页游标，复用现有 AES-GCM 加密存储。缓存上限沿用 1000 条。
- 连接完成认证后自动刷新当前查询的首批 5 条，后台连接同样适用。刷新期间保留上次列表，成功后替换。
- 600 毫秒内连续点击两次底部“会话”标签手动刷新；已有请求时不重复发送。单击或普通页面切换直接显示缓存，保留当前列表与滚动位置。
- 搜索更改重新查询；加载更多仍追加 10 条并按 ID 去重。已有缓存行的状态可随服务端摘要增量更新，不重新请求列表。
- 失败或 15 秒超时保留旧列表并显示简短提示；断线可读缓存，重连自动刷新。移除绑定清除对应本地数据；重新配对清空列表缓存。
- 列表读取位置在本次进程内按电脑保留；本轮不承诺进程终止后的像素位置恢复。
