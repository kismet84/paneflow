# 官方 Codex 桌面会话接入

日期：2026-11-03。当前实现为 Windows 官方桌面端本机插件通道适配，未改变官方程序或抢占写锁。

## 工作方式

用户在已配对移动端选择被官方桌面占用的会话，点击“尝试接管”。Windows 配套端通过官方桌面插件的本机命名管道验证该会话，按设备、会话和管道实例建立控制授权。发送调用原桌面进程的 send_message_to_thread；正文和历史仍以原会话为准，不新建或分叉会话。

释放仅撤销当前设备控制，保持历史阅读和草稿，不取消官方订阅，不停止任务或进程。切换失败保留原控制边界；控制发送失败或中转连接重建撤权恢复只读，不自动重发不确定消息。

## 能力范围

| 能力 | 官方接入会话 | PaneFlow 自有会话 |
|---|---|---|
| 历史、复制、分页、附件只读访问 | 保留 | 保留 |
| 消息同步 | 2 秒轮询 | 原协议事件 |
| 空闲时文本续聊 | 原官方进程执行 | 原 app-server 执行 |
| 运行中插话 | 暂未开放 | 原能力 |
| 停止、审批、模型配置、分叉 | 请在官方桌面端操作 | 原能力 |
| 新附件发送 | 暂未开放，已有附件草稿保留 | 原能力 |

官方桌面端必须保持开启；未发现通道或发现多个实例时拒绝接管。通道是当前官方桌面安装插件使用的内部接口，并非承诺跨版本兼容的公共 API。升级官方桌面后需复验；失败保持只读。适配器仅允许读取会话和发送消息，不向网络提供任意本机工具调用。

## 验证记录

- 通过当前安装的官方插件源码确认 4 字节小端长度帧与 tools/call 协议，接口仅开放 read_thread/send_message_to_thread。
- 独立验收会话经官方通道续写，返回 OFFICIAL_CHANNEL_READY；Windows 写锁持有者为官方 Codex app-server 进程。原会话 ID 保持相同。
- 全量 360 项测试通过；含设备隔离、重复请求不重发、附件变更拦截、失败切换保留授权、释放不取消官方订阅、中转重连撤权、单实例选择和发送断连。
- Android 构建和 17 项单元测试通过。
- 本机 Windows 配套端已更新，公网域名、配对身份和登录自启保持原配置。没有停止或重启官方 Codex 进程。
- 华为帐号验证后，新版通用 APK 已覆盖安装到 MatePad；原配对保留，公网连接通过。
- 平板点击尝试接管后显示“已接管 · 官方 Codex · 空闲”，输入框解锁；从平板发送消息，原会话返回 TABLET_OFFICIAL_CONTROL_OK 1680，正确沿用先前算式结果。
- 原生 UI 循环测试通过（1 项，60.205 秒）：释放恢复只读、草稿保留、重新接管恢复草稿、再次释放；只操作指定独立验收会话。
- 释放后官方端仍能在原会话继续，返回 OFFICIAL_AFTER_RELEASE_OK；平板只读同步收到该回复，输入和发送保持禁用。
- 发送前后及释放后的写锁持有者均为同一个官方 app-server 进程；未终止或重启官方进程。全过程未锁屏。
- 本轮仅 MatePad 真机验证，未冒称 OPPO 本轮复验。

原始会话、管道地址及屏幕证据仅保存在忽略目录 outputs/completion-live，不发布个人信息。


发布归属：上述真机记录对应0.8.0增量构建；0.8.1同步包含这些功能，发布构建、签名与产物核对见 [0.8.1发布验证](RELEASE-0.8.1.md)。
