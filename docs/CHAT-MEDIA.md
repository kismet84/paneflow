# 聊天与多媒体（0.8）

保留原生 Java 聊天、配对、任务控制、模型/推理强度、独立会话和可靠回执。新增能力按 `attachmentsV1` 协商，旧电脑可继续文字聊天，附件入口提示升级。

## 阅读

- 原生 Markdown：标题、粗斜体、删除线、引用、嵌套列表、任务框、链接、横向表格、代码块复制与长代码展开。没有 WebView；HTML 显示为文字，链接仅 HTTP(S)。暂不提供数学公式、脚注或代码语法着色。
- 长回答展开/收起、全文复制；真实 plan 项作为计划卡片，可导出 Markdown。
- 较早消息与连续已完成工具活动可折叠，失败、运行、待审批项保持可见。折叠只影响显示，不删除服务器历史或压缩模型上下文。
- 历史分页和阅读锚点保留；读旧消息时出现回到最新消息按钮。折叠状态按电脑和会话加密保存。

## 图片与文件

1. 打开对应电脑的会话，点输入栏加号选择图片、文件或拍照。
2. 文件先复制到手机私有加密缓存，显示草稿附件；每条消息最多 8 个，每个 1 字节至 20 MiB。
3. 点击上传。传输通过原有端到端加密连接，使用 48 KiB 分块和 SHA-256 完整性检查。断线后点击重试，先核对服务器偏移；不会因此发送聊天任务。
4. 所有附件上传完成后，点击发送。可以只发送附件，也可附文字。发送结果不明确时先查回执，不能自动重复执行。
5. 聊天显示已缓存图片缩略图；首次未缓存图片点击加载。图片可全屏缩放、保存及分享；文件可保存、分享。

手机缓存使用 Android Keystore 加密，100 MiB 配额。电脑使用受控附件目录，元数据由系统保护；文件正文供本机 Codex 读取，**不是电脑磁盘加密存储**。电脑端总配额 512 MiB，单上传设备 128 MiB。附件不保存到公开 Git 仓库。

桌面已有受管 `media` / `files` 目录中、真实会话明确引用的附件可注册到手机历史；任意 Windows 路径、外部图片 URL 不会自动开放下载。外部路径、过大、已清理的旧附件可能不可用；上传成功也不代表模型一定能解析该文档格式。

“发送与操作记录”显示附件归属。仅明确失败或人工核对未执行后才能恢复到草稿，不自动发送。清理本机已完成缓存不会删除远端历史；待核对材料保留。删除电脑副本需要单独确认，会使远端历史附件不可再下载，不能撤销。

## 语音转文字

点击麦克风，允许权限后由手机系统语音识别服务识别。结果可编辑，点“填入草稿”后还需手动发送。离开页面或应用停止录音；取消不发送。系统没有识别服务时明确提示，可使用键盘输入。识别是否离线取决于手机服务，不能承诺 OPPO 的所有系统版本都可用。
