# PaneFlow 0.8.2

发布日期：2026-11-03。

修复 Android 更新误提示“还有运行中或未知状态的会话”：历史列表包含其他 Codex 进程及未知历史，不再要求这些记录全部空闲。当前轮次、完整队列、审批、未确认回执、快照时效、数据备份和安装包校验仍保留，Windows 升级条件未放宽。

- 手机和平板使用同一 `PaneFlow-Android-0.8.2.apk`，版本 0.8.2 / 12，包名和原型 debug 签名保持一致，覆盖安装保留绑定。
- 旧 0.8.0／未修复的 0.8.1 如果已被错误检查拦住，请直接下载本版本 APK，通过系统安装器覆盖一次；不要卸载、清数据或停止无关电脑任务。
- Windows 同步重打 0.8.2 安装包以保持更新清单一致，电脑执行逻辑未改；本次发布不会自动升级本机运行实例。
- 保留此前真实会话、官方接管与释放、草稿、附件、通知和公网重连能力。

修复源码已在 MatePad Pro 的本地 0.8.1 修复构建验证：17 项单元测试、8 项更新设备测试、真实 74 条运行／未知历史记录不误拦截、官方会话接管／释放及草稿保留、公网故障自动重连。文字重连验收前后 10 个消息 ID 一致，请求账本未增加操作，原绑定保留，全程未锁屏。0.8.2 使用相同功能源码提升发布版本，另行执行构建、签名、校验值和远端产物核对；未将版本重打包记作再次真机安装。

Android 沿用原型 debug 签名，Windows 安装包未使用代码签名证书。更高版本的完整应用内覆盖安装仍需由用户确认系统安装；后台服务仍受 Android 系统限制。

详见 [更新记录](https://github.com/kismet84/paneflow/blob/v0.8.2/CHANGELOG.md) 和 [修复及验证范围](https://github.com/kismet84/paneflow/blob/v0.8.2/docs/FIX-ANDROID-UPDATE-GUARD.md)。下载后按同一 Release 的 `SHA256SUMS.txt` 核对文件，`update.json` 同步提供版本、兼容范围、大小和哈希。
