# 被占用会话的只读模式

2026-11-02，本地增量实现，基线 Git 06cefca；尚未提交或更新公开 Release。

## 行为

- thread/resume 明确报 already has an active writer 时，以只读方式打开；其他错误不降级、不删除锁、不接管桌面进程。
- 输入框灰色显示“只读 · 电脑正在使用”。原草稿隐藏但持久保留；解除只读后恢复。
- 发送、停止、审批、模型修改、分叉、语音、新附件及附件删除禁用；客户端命令层与桌面端再次校验。
- 保留历史、复制、折叠、分页、已获授权附件的读取与预览。其他电脑/会话操作不受影响。
- 每2秒轮询已连接只读会话的最新一轮，同ID更新、跨轮合并，保留300项窗口；更早内容按1轮分页加载。断线或撤销授权后停止同步，不自动取得写入权。
- 超过10秒未成功读取显示“同步暂缓”。同步延迟还取决于Codex保存消息的时机及网络，不承诺逐token即时推送。
- 菜单“尝试接管”只在用户点击后重试；成功才恢复输入。

## 修复的验证发现

整段thread/read(includeTurns:true)在本长会话超过app-server IPC单行上限；现用只读元数据 + 最新1轮分页，避免全量读取。维护模式停止轮询与附件登记；同会话刷新合并消息，避免新轮次让上一轮消失。
